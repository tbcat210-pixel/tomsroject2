# ポケポケ対戦確率計算シミュレーター(β)

ポケポケの20枚デッキを入力し、初期手札や各種カード処理を含めて「狙うカード」がそろう確率をモンテカルロ法で計算するブラウザ完結型シミュレーターです。

## 主な機能

- 20枚デッキ固定、最大20種類のカード入力
- 各カードは1枚 / 2枚をボタンで指定
- カード分類：たね / 進化 / トレーナーズ
- 初期5枚は「たねポケモン最低1枚」を保証する条件付き抽選
- 狙うカードを複数選択し、選択カードがすべて1枚以上そろう確率を計算
- 博士の研究を個別処理
- モノマネむすめを個別処理（相手手札2 / 3 / 4枚）
- モンスターボールを最大2枚まで使用
- 「サポート → モンボ」「モンボ → サポート」の使用順を考慮
- 「博士 / モノマネ / 使用後の手札が多い方」を選択可能
- 初期ドロー、2ターン目ドローをON/OFF可能
- 博士・モノマネ・モンボの使用順ごとの成功率比較
- 具体的な1試行の進行例を表示

## 使い方

`index.html` をブラウザで開くだけで動作します。サーバーやビルド作業は不要です。

## GitHub Pages で公開する方法

1. このフォルダのファイルをGitHubリポジトリのルートへアップロードします。
2. GitHubのリポジトリで `Settings` → `Pages` を開きます。
3. `Build and deployment` の Source を `Deploy from a branch` にします。
4. Branch を `main`、フォルダを `/ (root)` にして保存します。
5. 公開URLが表示されたら、そのURLからシミュレーターを利用できます。

## 注意

- 確率は乱数を使ったシミュレーション値です。試行回数を増やすほど値は安定します。
- β版のため、ポケポケ本体の仕様変更や想定していないカード処理には未対応の場合があります。
- 特殊処理はカード名「博士の研究」「モノマネむすめ」「モンスターボール」の完全一致で判定します。
